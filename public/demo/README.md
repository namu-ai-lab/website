# Demo recordings

Real output of Tafiya (`POST /v1/speech`), generated once through the Namu API on 2026-10-20, one per script and
voice: `<script>-<voice>.m4a` with scripts `news`, `clinic`, `market`, `tale` (texts in `src/content/playground.ts`)
and voices `nadia` (shown as Female) and `salim` (shown as Male). AAC, mono, 64 kbit/s.

The home console plays these first and falls back to the live demo for anything not recorded here. If a script's
text changes, regenerate its two files, or the console will play the old sentence.
